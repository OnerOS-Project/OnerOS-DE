# OnerOS DE

A modern, lightweight desktop environment built for OnerOS.

OnerOS DE is a desktop environment in development, designed to provide a modern, intuitive and customizable Linux desktop experience.

The project aims to combine the simplicity and consistency of macOS, the familiarity and convenience of Windows, and the flexibility of Linux — while keeping the interface lightweight, responsive and visually cohesive.

## ✨ Vision

OnerOS DE aims to make the desktop feel natural to use without sacrificing control or customization.

Our goals include:

- Clean, consistent design — a modern interface with subtle transparency, dark surfaces and blue accents.
- Lightweight performance — responsive interactions and efficient resource usage.
- Customization — control over appearance, themes, wallpapers and desktop behavior.
- A complete desktop experience — windows, applications, notifications, system settings and essential desktop tools.
- Linux compatibility — integration with existing Linux applications and system services.
- Room to grow — an architecture that can evolve alongside the wider OnerOS project.

## 🖥️ Planned Features

OnerOS DE is intended to include:

- A customizable desktop and wallpaper system.
- A system panel with a clock and status indicators.
- An application launcher and application switcher.
- Window management, including moving, resizing and maximizing windows.
- A control center for quick access to common settings.
- Notifications and system alerts.
- Settings for appearance and desktop behavior.
- Integration with networking, audio, brightness and power controls.
- Support for multiple monitors.
- Compatibility with Linux applications.

These features describe the project's direction. Their availability will depend on development progress.

## 🎨 Design

OnerOS DE follows a consistent visual language built around:

- A dark, modern interface.
- Subtle transparency and glass-inspired surfaces.
- Blue accent colors.
- Clear typography and recognizable controls.
- Smooth, restrained animations.
- Responsive layouts and accessibility.

The goal is a desktop that feels polished without letting visual effects get in the way of usability or performance.

## 🛠️ Technology

OnerOS DE is being developed as a native desktop environment, not simply as a web interface.

The planned technical direction focuses on Linux and Wayland, with Rust being considered for components where it offers meaningful benefits. Smithay is a candidate for the Wayland compositor layer.

The final technology choices will depend on implementation requirements, compatibility and performance testing.

## 🧭 Roadmap

Development will progress in stages:

- Foundation — establish the architecture, development environment and core technologies.
- First Prototype — get a minimal desktop session running.
- Desktop Shell — introduce the panel, desktop, launcher and basic interface.
- Window Management — support application windows and essential window operations.
- System Integration — connect audio, networking, power controls and notifications.
- Settings & Customization — add appearance options and desktop preferences.
- Stability & Compatibility — improve reliability, multi-monitor support and application compatibility.

The roadmap may change as development progresses.

## 🧪 Project Status

OnerOS DE is in early development.

The project is working toward its initial native implementation. Features listed in this README are planned goals unless explicitly identified as implemented.

Expect architectural changes, incomplete functionality and breaking changes while the foundations are being built.
